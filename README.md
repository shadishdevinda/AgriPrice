AgriMarket is a web platform that provides agricultural and economical support for farmers. This project is developed using Laravel, PHP, HTML, CSS, JavaScript, and MySQL.

- [Technologies Used](#-technologies-used)

## 🚀 Features

- Providing Day-to-day market price updates.
- Providing crop advice.

## 💻 Technologies Used

- **Laravel** - 🌐 PHP web framework
- **PHP** - :elephant: Server-side scripting language
- **HTML** - 📄 HyperText Markup Language
- **CSS** - 🎨 Cascading Style Sheets
- **JavaScript** - :gear: A programming language for the web
- **MySQL** - 🗃️ Relational database management system

## 🌐 Usage

Explore crop price updates and advice for free on our website. If you own an economic center and wish to display your prices, simply contact us. Upon registration, you can log in and effortlessly update your economic center prices.
